# Sources and version references

Course structure: the attached BusinessProgramming_3Week_Android_Guide(1).pdf, especially pages 3–4, 14–15, 25–29 and 32. The UstaGo kit adapts its product/cart flow into a vehicle/service appointment flow; it does not claim to be the SavdoShop starter archive mentioned by that PDF.

Official references checked while preparing this kit:

- AGP 8.13 / 8.13.2, Gradle 8.13 and JDK 17 compatibility: https://developer.android.com/build/releases/agp-8-13-0-release-notes
- Compose compiler plugin for Kotlin 2.0+: https://developer.android.com/develop/ui/compose/setup-compose-dependencies-and-compiler
- Room release history including 2.8.4: https://developer.android.com/jetpack/androidx/releases/room
- KSP release history: https://github.com/google/ksp/releases
- Navigation release history including 2.9.5: https://developer.android.com/jetpack/androidx/releases/navigation
- Lifecycle release history including 2.9.4: https://developer.android.com/jetpack/androidx/releases/lifecycle
- Compose BOM: https://developer.android.com/develop/ui/compose/bom
- Room documentation: https://developer.android.com/training/data-storage/room
- App signing: https://developer.android.com/studio/publish/app-signing

These links establish platform APIs/version guidance. They do not establish that this newly authored UstaGo source has compiled; local Android Studio verification is still required.
